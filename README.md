# ArcDock v0.1.0
Isolated Android build branch for ArcDock (NOT the Mineradio app).
- Android WebView offline UI + Java bridge for native launcher shortcuts.
- Actions workflow produces debug-signed installable APK, uploads Actions artifact, and publishes a GitHub Releases direct-download APK.
- No cloud service, no server, no system-wide overlay in v0.1.0.
- App ID: dev.arcdock.app
- Source project from user-facing ArcDock v0.1.0 package.
- The repository's main branch has not been changed.
